
# ApexPlanet Data Analytics Internship
## Task 2 - EDA, SQL Analysis and Dashboard

### Objective
Explore the cleaned sales dataset, identify business patterns,
perform SQL analysis, and create a static dashboard.

### Dataset
- Records: 1,000
- Columns: 12
- Source: Dataset provided for ApexPlanet Task 1

### Exploratory Data Analysis
- Reviewed dataset structure and data types.
- Calculated summary statistics.
- Analyzed sales by category, city, and product.
- Created charts for category and city sales.

### SQL Analysis
Used SQLite to analyze:
- Total sales
- Sales by category
- Sales by city
- Top 5 products by sales
- Quantity sold by product
- Average customer age by gender

### Dashboard
Created a static dashboard showing:
- Sales by category
- Monthly sales trend
- Total sales, record count, average sale, and quantity sold

### Tools Used
- Python
- Pandas
- Matplotlib
- SQLite
- SQLAlchemy
- VS Code

### Project Files
- eda.py - Exploratory data analysis
- sql_analysis.py - SQL queries
- dashboard.py - Dashboard generation
- data/cleaned_dataset.xlsx - Cleaned dataset
- charts/ - EDA charts
- dashboard/sales_dashboard.png - Static dashboard
- sql/sales.db - SQLite database

### Conclusion
The project summarizes sales performance across products,
categories, cities, and months using Python, SQL, and charts.
